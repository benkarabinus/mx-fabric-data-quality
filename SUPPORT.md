# Support

This repository is a sample: a proof of concept showing a metadata-driven data-quality
pattern for HL7 v2 and CCDA messages on Microsoft Fabric. It is provided as-is, with no
service-level agreement and no Microsoft support.

## Getting help

- **Deployment problems** — start with the Troubleshooting section of
  [docs/Deploy.md](docs/Deploy.md).
- **Changing fields, rules or participants** — see [docs/Extend.md](docs/Extend.md).
- **Bugs** — open a GitHub issue. Search existing issues first, and include the
  failing step and its output. Do not paste real patient data or credentials.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
